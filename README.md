# Neuronaut

A game played inside Qwen3.5-4B. Push one of its 294,912 neurons while it writes and it might start talking about the
sea, turn into a doctor, or fall apart. Most do almost nothing. The game is finding the ones that don't.

Play at [neuronaut.ishaanko.com](https://neuronaut.ishaanko.com).

- **Daily.** One neuron is hidden. Read what it does to the model, then find it in 15 guesses.
- **Dex.** Search neurons, scan them, catch the good ones.
- **Bounties.** Steer the model toward a target, like French or the sea.
- **Lab.** Push two neurons at once and see if their effects add up.
- **Map.** Strong neurons laid out by what they do.

To run your own copy (needs a 16 GB GPU), see [docs/running.md](docs/running.md).

Built on [neuron-explorer](https://github.com/lyramakesmusic/neuron-explorer) by
[lyramakesmusic](https://github.com/lyramakesmusic), which is where the steering method, the steer lens and the neuron
index come from.
